See [README.md](README.md) for this plugin.

Read EmDash documentation with `npx mcporter list emdash-docs` and
`npx mcporter call emdash-docs.search_docs query:"your question"` from the
repository root, rather than browsing the website. mcporter 0.17.0 requires
Node.js 24 or newer.

How work runs here:

- Code follows [CODING_STANDARDS.md](CODING_STANDARDS.md); terms follow [docs/GLOSSARY.md](docs/GLOSSARY.md).
- Tickets: [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md). Review tiers: [docs/agents/review.md](docs/agents/review.md). Merging: [docs/agents/merging.md](docs/agents/merging.md).
- The v1 design is [docs/specs/v1-page-builder.md](docs/specs/v1-page-builder.md), with its decisions in [docs/adr/](docs/adr/).
